# Примеры использования библиотеки cbr_key_rate

В этой директории находятся примеры использования библиотеки для получения и анализа ключевой ставки ЦБ РФ.

## Файлы

### 1. `basic_usage.py` — Базовое использование

Простой пример получения истории ключевой ставки:

```bash
python examples/basic_usage.py
```

**Что делает:**
- Загружает данные за указанный период
- Создаёт DataFrame с колонками "Дата" и "Ставка"
- Выводит статистику (мин, макс, среднее)
- Сохраняет результаты в CSV

### 2. `advanced_usage.py` — Расширенный анализ

Пример с анализом изменений и визуализацией:

```bash
python examples/advanced_usage.py
```

**Что делает:**
- Загружает полную историю ставки
- Рассчитывает изменения между датами
- Подсчитывает количество повышений/понижений
- Строит график динамики
- Сохраняет расширенные данные и график

## Требования

Для запуска примеров убедитесь, что установлены зависимости:

```bash
pip install pandas matplotlib
```

Библиотека `cbr_key_rate` должна быть установлена или доступна в PYTHONPATH.

## Быстрый старт

```python
from cbr_key_rate import fetch_full_key_rate_history

# Получить данные
history = fetch_full_key_rate_history("01.01.2020", "31.12.2024")

# Преобразовать в DataFrame
import pandas as pd
df = pd.DataFrame(history, columns=["Дата", "Ставка"])
print(df)
```
